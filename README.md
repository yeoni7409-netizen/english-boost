# English Boost — 영어 학습부진 중학생을 위한 웹앱 (2조)

슬라이드 기획을 그대로 구현한 React(Vite) 앱입니다.

| 기획 | 구현 위치 |
|---|---|
| 진단평가 Step 1~4 (파닉스·사이트워드·콜로케이션·라이팅) | 처음 접속 시 자동 진행 → 약한 영역부터 시작 |
| 큰 단계 5개 / 작은 단계 | `src/data.js` 의 `STAGES` |
| 별점 최대 3개, 점수 비공개, 재도전 | 결과 화면 · 학습 지도 |
| 개인 기록 (최장 연속일, 하루 최다 클리어, 실제 풀이 집중 시간) | "내 기록" 탭 |
| 연속 학습 3→7→14→30→60일 포인트 | "내 기록" 탭 |
| 주 5일 참여 보너스, 뱃지 소액 포인트 | 자동 지급 |
| 주간 리그 (상위 승급·하위 강등, 내 위아래 3명만 공개) | "리그" 탭 |
| 보상 상점 (캐릭터 수집 + 교환 쿠폰) | "상점" 탭 |

## 내 컴퓨터에서 실행
```bash
npm install
npm run dev
```

## Vercel 배포
1. 이 폴더를 GitHub 저장소에 올립니다.
2. vercel.com → **Add New → Project** → 저장소 선택
3. Framework가 **Vite**로 자동 인식됩니다 → **Deploy**

(GitHub 없이: `npm i -g vercel` 후 이 폴더에서 `vercel` 실행)

## Lovable로 가져가기
- Lovable에서 GitHub 저장소를 연결해 이 코드를 불러온 뒤, 채팅으로 "디자인을 더 게임처럼 바꿔줘", "문제 추가해줘" 식으로 이어서 수정할 수 있습니다.
- Lovable 프로젝트는 TypeScript 템플릿이라, 불러올 때 파일을 `.tsx`로 바꿔 달라고 하면 맞춰 줍니다.

## 문제 추가/수정
`src/data.js`만 고치면 됩니다. 문제 유형: `listen`(듣고 고르기), `flash`(순간 제시), `choice`(고르기, `timer` 선택), `order`(어순), `fill`(틀 채우기), `write`(그림 보고 쓰기).

## 지금 버전의 한계 (다음 단계)
- **기록은 각 학생의 브라우저에만 저장**됩니다. 기기를 바꾸면 기록이 이어지지 않아요.
- **리그는 '연습용 가상 친구'와 경쟁하는 데모**입니다. 실제 반 친구들과 경쟁하려면 로그인 + DB(Lovable의 Supabase 연동 등)가 필요합니다.
- 실제 학생 데이터를 서버에 저장하게 되면 **미성년자 개인정보**이므로, 실명 대신 닉네임을 쓰고 학교/보호자 동의 절차를 확인하세요.
- 쿠폰은 앱 안에서 발급만 되고, 실제 지급은 선생님이 확인 후 해 주는 방식입니다.
- 발음은 브라우저 내장 음성(TTS)을 씁니다. 크롬/사파리 권장.
